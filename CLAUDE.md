# CLAUDE.md

## Code Review Guidelines
- Always check for edge cases and error handling
- Flag potential performance issues
- Ensure adherence to SOLID principles
- Verify input validation and security best practices

## Documentation Style
- JSDoc for every public function
- Explain all parameters and return values
- Include a usage example where relevant
- Documentation should be written in English


## Code Style
- Language: TypeScript
- Commit messages: imperative mood (e.g. "Add login feature")
- Branch naming: feature/, fix/, chore/
